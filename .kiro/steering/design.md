# Design rules

The UI must feel premium and calm, not vibe coded.

- Off-white background, near-black text, ONE accent colour: phosphor green (#2BD46B) used sparingly
- The only dark element is the "green screen" terminal panel that shows the old COBOL code, like a 1970s mainframe
- Huge, tight, bold headlines. One short idea per section
- Numbered steps shown as "01 / 03 Exhume", "02 / 03 Resurrect", "03 / 03 Seance"
- Slow, calm fades and eases. No flashy or bouncing animation
- Spooky through restraint: subtle language (exhume, resurrect, seance, restless spirit), not cartoon ghosts everywhere
- Use real data and real outputs, never placeholder content
